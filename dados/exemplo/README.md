# Pacote de exemplo

Relatórios fictícios no mesmo formato do Smart Report, com uma semana (07 a 13/09/2026) de
três linhas inventadas. É o que os testes usam.

- `Setembro_2026/Mensal/`: os 11 relatórios de um pacote completo
- `com_erros/Mensal_202609.html`: Resumo Geral com um km negativo e uma data inválida (teste da RN05)

Para mudar o exemplo, edite `scripts/gera_exemplo.py` e rode de novo.
